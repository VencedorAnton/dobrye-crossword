# Добрые Кроссворды — v0.23b / Ornament Word Filling

## Результат (черновик для редакторской проверки)

Из девяти проверенных орнаментов v0.22 (11×11, 13×13 и 15×15) получены **9 полностью заполненных кроссвордов** с реальными русскими словами и определениями.

- **216 ответов / определений**, **208 различных ответов**.
- **3 узора × 3 размера:** Снежинка, Бабушкин квадрат и Паутина.
- Все белые клетки заполнены; каждое слово соответствует слоту; все пересечения согласованы.
- В пределах одного кроссворда одинаковые ответы не повторяются.
- **16 слов** предварительно отмечены для оценки сложности и уместности для пожилых игроков.
- Между разными кроссвордами пока есть **8 повторяющихся ответов** — можно сократить перед выпуском.

### Просмотр

https://vencedoranton.github.io/dobrye-crossword/ornamental-crosswords-filled-v023b.html

Пользователь может переключить 11×11 / 13×13 / 15×15, выбрать один из трёх орнаментов, открыть определение, подсветить слово, увеличить клетки и показать/скрыть ответы. **Это предпросмотр, не игра с вводом букв.**

### Файлы

- `filled_ornaments_11x11_v023a.json` — первый эксперимент с тремя 11×11, с черновыми определениями.
- `filled_ornaments_v023b.json` — полный набор из 9 заполненных орнаментов и определений.
- `verify_fill.py` — независимая проверка геометрии, номерации, пересечений, уникальности, полноты решения и определений.
- `../ornament-scaling-v022.json` — исходные геометрические шаблоны (остаются неизменными).
- `../ornamental-crosswords-filled-v023b.html` — автономный HTML-предпросмотр с встроенными данными.

### Локальная проверка

Из корня проекта (Python 3.9+, без сторонних зависимостей):

```sh
python generator_v023/verify_fill.py
```

Критерий: `PASS: 9/9 сеток; 216/216 слов и определений.`

### Важные ограничения

1. **Редакторская корректность и доступность не сертифицированы.** Определения составлены как черновики, часть унаследована из v0.21; формальный второй проход ещё не состоялся.
2. **Лексические риски:** `БЕРИЛЛ`, `ЗЕНИЦА`, `АБСОЛЮТ`, `АДЕПТ`, `АПЛОМБ` и другие отмеченные слова могут оказаться слишком сложными для части аудитории.
3. В исходном словаре иногда использована `Е` вместо `Ё` (например, `АКТЕР` вместо `АКТЁР`). До публикации нужна согласованная политика `Е/Ё` и проверка вводимых ответов.
4. Заполнение осуществлено офлайн, редакторским пакетом решений, **не на телефоне игрока**. Следующий этап — воспроизводимый генератор, рейтинг словаря/сложности и тематические наборы.
5. **Основная опубликованная игра не изменена.** Никакие новые сетки не импортированы туда без отдельного контроля качества.

### Следующий релизный шлюз

- Редактору просмотреть 216 пар слово/определение, заменить неоднозначные, редкие или неуместные, проверить грамматику.
- При замене ответа пересчитать пересечения; нельзя просто заменить слово одной длины.
- Избавиться от повторов между соседними уровнями, насколько это допускает геометрия.
- Проверить 11×11 и 15×15 с крупным шрифтом на реальном Android-смартфоне, с учётом слабого зрения и моторики.
- Только после QA — переносить одобренные уровни в игровую базу.
