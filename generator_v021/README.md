# Добрые Кроссворды — v0.21 (Template-first generator)

## Результат

- Создан экспериментальный Python-генератор симметричных масок **11×11** с поворотной симметрией 180°.
- Маски формируются **из правильной исходной сетки** изменением симметричных пар клеток. Каждый кандидат заново проверяется.
- Проверки: отсутствие последовательностей из 2–3 клеток; длина всех слов 4–9; все белые клетки относятся к словам; единая связная сеть пересечений; у каждого слова есть пересечение; нет белых блоков 2×2; точная симметрия.
- Заполнение: **backtracking + MRV** (сначала самый ограниченный слот), индексы по позиции буквы, запрет повтора ответа, лимит поисковых узлов и воспроизводимый seed.
- **4 разные сетки с заполненными словами и написанными определениями** доступны как демонстрационные образцы.
- Автоматически сгенерированные варианты, у которых отсутствуют проверенные определения, помечаются `needs_clues` и **не выпускаются в игру**.

## Просмотр

Откройте: **https://vencedoranton.github.io/dobrye-crossword/symmetric-generator-v021.html**

Можно выбрать любой из четырёх вариантов, подсветить определение, показать ответы и увеличить размер клеток. Это **не игровой режим с вводом букв**; опубликованная основная игра v0.18 не изменялась.

## Файлы

- `generator.py` — полностью офлайн, Python 3.9+, без сторонних Python-библиотек.
- `data/mit_russian_nouns.txt` — слова-кандидаты, исходный список 3261 запись; после удаления неподходящих длин и повторов набор немного меньше.
- `data/THIRD_PARTY_LICENSE.txt` — информация об авторстве и лицензии MIT.
- `examples.json` — 4 подготовленные сетки с определениями и решениями.
- В корне репозитория `symmetric-generator-v021.html` — автономная HTML-страница предпросмотра (данные внутри файла).

## Запуск локально

Из корня репозитория:

```bash
python generator_v021/generator.py --verify
python generator_v021/generator.py --count 5 --attempts 100 --seed 20261021
```

Файл с автоматически созданными кандидатами: `generator_v021/generated_candidates_v021.json`.

Проверка работы **только со словами, которым уже вручную составили определения**:

```bash
python generator_v021/generator.py --count 3 --attempts 100 --require-clues
```

Если такого ограниченного словаря недостаточно для заполнения, скрипт честно сохранит 0 готовых кандидатов.

## Критерии допуска новых кроссвордов

1. Все слоты и пересечения валидны, нет искусственных 2–3-буквенных хвостов.
2. Все слова — самостоятельные существительные, знакомые русскоязычным игрокам; редкие, двусмысленные, просторечные, грамматически сомнительные и неэтичные слова — на ручную отбраковку.
3. Все определения написаны по-русски, однозначны и соответствуют ответу.
4. Качество и плотность пересечений удобны для пожилых пользователей, нет мелких неразличимых блоков.
5. В основную игру не переносить автоматически созданные партии без проверки.

## Ограничения v0.21

- Генератор исследует **вариации одной исходной качественной геометрии**, а не все существующие виды симметричных кроссвордов. Формы уже действительно различаются, но визуальное разнообразие нужно расширять.
- Словарь из стороннего проекта — только **источник кандидатов**, не профессионально выверенная база с определениями.
- Примеры в `examples.json` — **общие знания**, НЕ тематические кроссворды.
- Автоматизированное тематическое заполнение, полностью редакторский словарь и интеграция в игровой интерфейс — следующие этапы.
- Генерация выполняется **до публикации игры**, а не на телефоне игрока.
