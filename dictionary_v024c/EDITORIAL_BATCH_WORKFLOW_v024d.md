# Совместная редактура — по три слова за раунд (v0.24d)

Мы редактируем **по 3 слова за одно сообщение**. Для каждого слова ассистент показывает текущее определение и 3 контрастных варианта: строгий, культурный/литературный/пословичный (если подходит), образный/непрямой. Пользователь отвечает одной строкой: `ЗАЯЦ 2; ЛУНА 3; КНИГА 1+2`, либо даёт собственный вариант для любого слова. Несколько выбранных определений для одного слова сохраняются как `clue_variants` одного лексического смысла. Каждое слово может иметь несколько тематических категорий.

**Важно:** GitHub меняется **только после ответа по всем трём словам**; три решения вносятся одним редактированием компактного файла `owner_clue_overrides_v024d.json`. Дальнейшая публикация кроссвордов остаётся заблокирована до отдельной проверки. Текущая игра `index.html` не редактируется.

Существующая редакторская запись `ЗЕРКАЛО` сохранена здесь: классическое определение «Предмет с гладкой поверхностью, отражающей свет и позволяющей человеку увидеть собственное изображение.» и литературное «В сказке Пушкина царица спрашивала его, кто на свете всех милее.»; категории «Дом и быт» и «Литература и классика». Основное отображаемое определение — классическое, литературное — второй вариант. Дополнительная смысловая подсказка «Так называют гладкую поверхность воды.» сохраняется.

**Важная техническая деталь:** этот файл переопределений не изменяет исторический `common_words_batch_001.json`. Для получения **полной актуальной редакторской версии** используется `python dictionary_v024c/build_owner_review_v024d.py --build` (сначала собирает словарь из исходного генератора, затем накладывает выбранные определения). Старый `build_enriched.py` без наложения показывает состояние до выбора «ЗЕРКАЛО».

Для работы с новой редакторской страницей отображаемый вариант «ЗЕРКАЛО» также внесён в `dictionary-review-v024c.html`. Экспорт браузера — только предложения и не означает публикацию или независимую проверку.

## Редакционный стандарт сложности — решение владельца 24.10.2026

**Целевая аудитория — эрудированные взрослые, в том числе пожилые.** Крупный шрифт и простое управление не означают примитивных вопросов. Отказываемся от подсказок, которые почти прямо называют ответ, и от бытовых описаний вроде «кошка мурлычет и ловит мышей». Не предлагать в литературном варианте тривиальную подстановку («Татьяна написала Онегину…»), если она не проверяет эрудицию.

- Предпочтение: культурно-исторический факт, литературная отсылка, точная научная деталь, география, этимология, устойчивая идиома, неожиданное второе значение.
- Ключевой критерий: для разгадки нужно **узнать что-то из памяти и связать факты**, а не просто завершить очевидное предложение.
- Точность важнее оригинальности: проверять факты, избегать стереотипов и вопросов с несколькими равноправными ответами; не упоминать ответ или производное от него в тексте определения.
- Подсказка должна соответствовать **единственному слову в словаре**; количество букв/пересечения служат дополнительной проверкой, а не оправданием двусмысленности.
- Варианты должны быть действительно разными по интеллектуальному механизму (история / литература / язык), а не тремя близкими пересказами.
- Ограничение интерфейса: **не более двух реально отображаемых строк при крупном шрифте**; предварительно целиться в 35–65 знаков, технический лимит редактора — 70 знаков. Не обрезать загадки многоточием.
- Положительный пример направления, предложенный владельцем: о кошке — связь с почитанием этих животных в Древнем Египте (лучше уточнять богиню Бастет ради однозначности). Это **пример редакционного стандарта**, а не автоматическая замена ранее выбранных вариантов.
- Когда владелец выбирает существующий вариант, сохранять его без самовольной замены, но все **следующие предложения** делать заметно интеллектуальнее.

Отобранные слова и определения остаются черновиками до отдельных проверок и выпуска игры.

## Исторические ответы: пример владельца (24.10.2026)

Для эрудированных игроков желательно спрашивать **конкретное место или имя**, а не родовое слово из слишком очевидного описания.

- **ЭЛЬБА:** «Остров первого изгнания Наполеона в 1814 году.»
- **ЕЛЕНА:** «Женское имя в названии острова, где умер Наполеон.»

У Наполеона было две ссылки: на Эльбу (1814), затем на остров Святой Елены (1815–1821), где он умер. Поэтому вопрос «На какой остров сослали Наполеона?» неоднозначен. Для ответа «ЕЛЕНА» необходимо указать, что требуется **имя из названия**, а не название острова целиком. Источник исторических фактов: Fondation Napoléon.

Эти пары — идеи для будущих кроссвордов, **не новые записи словаря**. Уже выбранные варианты «ОСТРОВ» сохраняются.
