# Совместная редактура — по три слова за раунд (v0.24d)

Мы редактируем **по 3 слова за одно сообщение**. Для каждого слова ассистент показывает текущее определение и 3 контрастных варианта: строгий, культурный/литературный/пословичный (если подходит), образный/непрямой. Пользователь отвечает одной строкой: `ЗАЯЦ 2; ЛУНА 3; КНИГА 1+2`, либо даёт собственный вариант для любого слова. Несколько выбранных определений для одного слова сохраняются как `clue_variants` одного лексического смысла. Каждое слово может иметь несколько тематических категорий.

**Важно:** GitHub меняется **только после ответа по всем трём словам**; три решения вносятся одним редактированием компактного файла `owner_clue_overrides_v024d.json`. Дальнейшая публикация кроссвордов остаётся заблокирована до отдельной проверки. Текущая игра `index.html` не редактируется.

Существующая редакторская запись `ЗЕРКАЛО` сохранена здесь: классическое определение «Предмет с гладкой поверхностью, отражающей свет и позволяющей человеку увидеть собственное изображение.» и литературное «В сказке Пушкина царица спрашивала его, кто на свете всех милее.»; категории «Дом и быт» и «Литература и классика». Основное отображаемое определение — классическое, литературное — второй вариант. Дополнительная смысловая подсказка «Так называют гладкую поверхность воды.» сохраняется.

**Важная техническая деталь:** этот файл переопределений не изменяет исторический `common_words_batch_001.json`. Для получения **полной актуальной редакторской версии** используется `python dictionary_v024c/build_owner_review_v024d.py --build` (сначала собирает словарь из исходного генератора, затем накладывает выбранные определения). Старый `build_enriched.py` без наложения показывает состояние до выбора «ЗЕРКАЛО».

Для работы с новой редакторской страницей отображаемый вариант «ЗЕРКАЛО» также внесён в `dictionary-review-v024c.html`. Экспорт браузера — только предложения и не означает публикацию или независимую проверку.
