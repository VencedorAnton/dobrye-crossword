# Добрые Кроссворды — Этап v0.24b: Dictionary Foundation

**Цель:** перестать хранить слова, определения и смысловые подсказки только внутри отдельных кроссвордов; перейти к единой, воспроизводимой словарной базе перед игровым этапом v0.25.

## Что создано

- **2 873** уникальных кандидата длиной 4–9 букв из существующего MIT-словаря (`generator_v021/data/mit_russian_nouns.txt`, оригинал 3 261 строка);
- плюс **1** редакторская поправка `ЛАДОНЬ`, которой нет в первоначальном списке;
- **2 874** уникальных слова-кандидата суммарно (включая 208 слов текущих кроссвордов);
- **208** нормализованных карточек слов с черновыми определениями; используются **216 раз** в девяти кроссвордах;
- **12** разных слов имеют смысловые подсказки (синоним или другое значение), из них две добавлены владельцем;
- **21** карточка отмечена флагом проверки (грамматика, сложность, Ё и т. п.);
- **0** слов пока имеют статус `approved` — публикация словаря заблокирована до редакторской проверки.

Кандидаты пока **не являются** проверенным словарём существительных, частотности или правильных начальных форм.

### Импорт двух пользовательских подсказок (22 октября 2026)

Из экспортированного файла `dobrye_crossword_review_v024b.json` добавлены дополнительные значения для **АРКАДА** (жанр компьютерной игры) и **АБСОЛЮТ** (марка водки). Сохранены оценки сложности «средняя» и пожелание считать оба слова формой единственного числа. Содержимое внесено в черновые словарные карточки, девять исходных кроссвордов и HTML-предпросмотры; **публикационное одобрение не выдано**. Подсказка для АБСОЛЮТ дополнительно отмечена `brand_reference_review` (упоминание алкогольной марки). Экспорт пользователя был основан на корректной SHA текущего словаря.

### Ключевые файлы

- [`draft_entries.json`](draft_entries.json) — один уникальный `lemma` на карточку, список значений `senses`, определений и `hint`, категории, поля будущей частотности/сложности, происхождение, флаги редактора, ссылки на использующие слово кроссворды.
- [`source_registry.json`](source_registry.json) — реестр источников и разрешений на импорт.
- [`inventory_report.json`](inventory_report.json) — проверенный учёт количества слов и переносов из девяти кроссвордов.
- [`editorial_queue.csv`](editorial_queue.csv) — таблица из 208 слов для ручной проверки.
- [`build_dictionary.py`](build_dictionary.py) — полностью офлайн Python 3.9+, без сторонних зависимостей; компиляция кандидатов и черновиков, сверка с сетками и контроль допуска в релиз.
- [`apply_review.py`](apply_review.py) — безопасный импорт локальных предложений из HTML-редактора в отдельный черновик.
- [`test_dictionary.py`](test_dictionary.py) — семь регрессионных проверок миграции, подсказок, источников и релизного шлюза.

### Интерактивный просмотр и исправления

**https://vencedoranton.github.io/dobrye-crossword/dictionary-review-v024b.html**

- Поиск по словам и определениям; фильтр нерешённых вопросов, подозрительных слов и подсказок.
- Можно редактировать формулировки, отмечать сложность, форму слова и решение о дополнительной проверке.
- Правки остаются в `localStorage` браузера, **не обновляют** GitHub и игровые данные.
- Кнопка экспорта отдаёт `dobrye_crossword_review_v024b.json`, который можно затем передать для проверки и внедрения.
- Для проверки экспортированных правок: `python dictionary_v024b/apply_review.py путь/к/dobrye_crossword_review_v024b.json`. Сохранится только **предлагаемая** версия `build/proposed_entries.json`, исходные определения и игровые сетки не изменятся.
- Скрипт отвергнет устаревший экспорт (несовпадение GitHub blob SHA), некорректный тип подсказки и буквальное раскрытие ответа.
- Поле «Выглядит правильно» **не является** окончательным редакторским одобрением.

## Как собрать словарь офлайн

Из корня репозитория:

```bash
python dictionary_v024b/build_dictionary.py --verify
python dictionary_v024b/build_dictionary.py --build
python -m unittest discover -s dictionary_v024b -p 'test_*.py' -v
```

Выход в `dictionary_v024b/build/`:
- `master_dictionary.json` — 2 874 записей: черновые редакторские карточки плюс чистые кандидаты без готового определения;
- `editorial_queue.csv` — очередь из 208 текущих карточек для редактора.

Проверка **разрешённых** дополнительных источников через собственный CSV:

```bash
python dictionary_v024b/build_dictionary.py --build --candidate-csv path/to/words.csv
```

Заголовки входного CSV: `word,source_id`. Все записи из источников с `allowed_for_candidate_import=false` будут отклонены. Новые слова будут **только кандидатами**: у них не появляются вымышленные определения или ложное состояние «готово».

Пример проверки допуска в выпуск:

```bash
python dictionary_v024b/build_dictionary.py --release
```

Сейчас команда обязана завершиться отказом: **нет ни одного независимо одобренного слова**. Для `approved` требуются заполненные сведения о проверяющем, дате, грамматическом статусе, чистые флаги и утверждённые значения/определения.

## Формат карточки

```json
{
  "id": "ru:КЛЮЧ",
  "lemma": "КЛЮЧ",
  "part_of_speech": "noun_candidate",
  "editorial_status": "draft",
  "senses": [
    {
      "definition": "Знак нотной записи в начале нотного стана.",
      "hint": {
        "kind": "alternate_meaning",
        "text": "Им открывают дверной замок."
      }
    }
  ]
}
```

Это **иллюстрация схемы**, не новая опубликованная карточка и не добавленное в один из девяти полей слово.

## Лицензии и будущие источники

Текущий список слов использует локальный файл MIT с приложенным [уведомлением об авторстве](../generator_v021/data/THIRD_PARTY_LICENSE.txt). Определения текущих кроссвордов — оригинальные **черновики, подготовленные ИИ**, а не дословные выписки из сторонних справочников.

Дополнительные источники рассматриваются, **но их контент ещё не импортирован**:

- **OpenRussian**: CC BY-SA 4.0; нужна атрибуция и проверка условий ShareAlike перед использованием извлечённых значений/грамматических данных.
- **OpenCorpora**: CC BY-SA 3.0; аналогичная проверка, в первую очередь для морфологии.
- **Wiktionary**: лицензионная проверка текстовых определений и конкретного датасета до импорта.

Добавление источника в реестр **не означает**, что его данные можно немедленно копировать в коммерческую базу.

## Нерешённые редакторские вопросы

1. Проверка реальной начальной формы, существительного, числа и написания Ё. В особенности `КУДРИ`, `КОЗНИ`, `ДАННЫЕ`; исключения `ОБОИ`, `ГУСЛИ` (проверить значение).
2. Исключить сложные и малоупотребительные слова; оценить частотность **по настоящему корпусу**, а не выдуманной оценке ИИ.
3. Проверить 208 значений/определений и смысловых подсказок; решить, что годится пожилой аудитории.
4. Расширять словарь, после решения лицензий, к нескольким тысячам **проверенных** слов, затем генерировать уровни из утверждённых значений.
5. Не переносить записи с `draft`/`candidate_only` в опубликованную игру.

**Основная игра, девять готовых сеток и старый генератор не изменены.**
